# 🛵 Kurýrská kalkulačka

Praktický desktopový nástroj pro kurýry, naprogramovaný v jazyce Python s grafickým rozhraním Tkinter. Aplikace slouží k přehlednému sledování výdělků, výdajů, dýšek a údržby vozidla v reálném čase.

## ✨ Hlavní funkce
- **Sledování financí:** Okamžitý přehled čistého zisku, dýšek a nákladů na palivo.
- **Správa profilů vozidel:** Podpora pro různé dopravní prostředky (včetně mého skútru Maxon Matador 125cc).
- **Hlídání servisu:** Automatické sledování servisních intervalů a nutné údržby.
- **Lokální úložiště:** Data jsou bezpečně ukládána a serializována ve formátu JSON.

## 🛠 Použité technologie
- **Jazyk:** Python
- **GUI Framework:** Tkinter
- **Formát dat:** JSON

2. Stáhni si zdrojové kódy tohoto repozitáře.
3. Spusť aplikaci příkazem v terminálu:
